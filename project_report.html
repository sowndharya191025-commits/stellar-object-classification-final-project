Problem & goals

What the project set out to solve

Problem statement

  • Manual classification of massive astronomical catalogues is time-consuming and difficult to scale.
  • Object classes can overlap in observed photometric properties.
  • A reliable classifier must learn nonlinear relationships among sky position, magnitudes, and redshift.
  • The goal is to build and evaluate models that accurately identify each stellar-object class.

Project objectives

  • Understand the structure and quality of the astronomical dataset.
  • Explore class patterns in photometric measurements and redshift.
  • Prepare features for supervised machine-learning models.
  • Compare multiple classification algorithms using consistent evaluation metrics.
  • Select the strongest model and interpret the practical findings.

Feature glossary

  • alpha, delta — celestial coordinates locating the object on the sky.
  • u, g, r, i, z — photometric magnitudes across five wavelength bands.
  • redshift — spectral displacement, strongly linked to distance and cosmological motion.
  • obj_ID, spec_obj_ID — object identifiers.
  • run_ID, rerun_ID, cam_col, field_ID, plate, MJD, fiber_ID — survey / instrument metadata.
  • class — target label used for supervised learning.
Exploratory data analysis

Finding structure, patterns, and discriminative signal

EDA examined how the target class relates to positional, photometric, spectroscopic, and identification feature groups — and which factors most influence the prediction.

Class distribution

20,000-record test share shown
Galaxy — 59,445 (59.4%) Star — 21,594 (21.6%) QSO — 18,961 (19.0%)

Galaxy is the most dominant class, followed by Star; QSO has the fewest observations. The dataset is moderately imbalanced, so a stratified train/test split preserves these proportions.

Mean redshift by class

strongest discriminative feature

Star sits at ≈ 0 redshift, Galaxy averages ≈ 0.42, and QSO reaches ≈ 1.72 with the broadest range — quasars show markedly higher redshift than the other classes.

Photometric distributions

u, g, and z bands are skewed and compressed; r and i bands are closer to bell-shaped. Because bands differ in range and scale, feature scaling is needed before modelling.

Feature correlation

Photometric bands correlate strongly with one another, and quasars stand out with visibly higher redshift than stars or galaxies.

Dropping non-informative columns

Comparing the correlation heatmap before and after removing identifier columns confirmed those columns added noise rather than predictive signal.

Data preprocessing

Getting the data model-ready

Cleaning & feature selection

  • No missing values were found in the dataset.
  • Identification-related columns were removed — they don't help predict class, add noise, and can cause overfitting.
  • The target variable class (Star, Galaxy, Quasar) was converted to numerical values using label encoding.

Scaling & splitting

  • Redshift and photometric magnitudes span different scales, so StandardScaler was used to standardize feature values.
  • The data was divided into X (input features) and y (target class).
  • A random state was set for consistent, reproducible results, with stratify = y to preserve class proportions.

Evaluation metrics

  • Accuracy — overall proportion of correct predictions.
  • Precision — reliability of positive class predictions.
  • Recall — ability to identify actual class members.
  • F1 score — harmonic balance between precision and recall.
  • Weighted averages account for the unequal class distribution across Galaxy, Star, and QSO.

Conclusion & future scope

What the project shows — and where it goes next

Key findings

  • The dataset is large and information-rich, supporting robust supervised learning.
  • Class imbalance makes stratified splitting and weighted evaluation important.
  • Photometric measurements provide complementary spectral information.
  • Redshift is a highly informative discriminator, especially for separating stars from distant objects.
  • Random Forest delivered the strongest overall predictive performance in this experiment.

Future scope

  • Hyperparameter optimization and cross-validation.
  • Feature engineering using colour indices such as u−g and g−r.
  • Exploring gradient boosting variants, neural networks, and explainable AI.
  • Deployment for real-time catalogue screening.
